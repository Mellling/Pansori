## 📜 게임 소개
[ 울려라! 판소리 ]는 판소리의 장단과 와리오웨어식 마이크로게임을 결합한 K-RETRO 리듬·순간 액션 게임입니다.  
플레이어는 소리꾼이 되어 점점 빨라지는 박자에 맞춰, 판소리와 전래동화의 핵심 장면을 압축한 마이크로게임을 연속으로 돌파해 20회 완주를 목표로 합니다.  
게임은 4회 성공할 때마다 제한 시간이 빨라지고, 4회 실패 시 게임 오버로 긴장감을 유지합니다. 총 9개의 마이크로게임으로 구성되어 있으며, 각 게임은 연습 모드에서 사전에 플레이할 수 있습니다.  
본 프로젝트는 유니데브 제4회 게임잼에서 약 3일간 개발한 5인 팀 프로젝트이며, 대상(장원상)을 수상했습니다.
